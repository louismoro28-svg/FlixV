# FlixV

A minimal SwiftUI iOS application for exploring movies and TV shows.

## Getting Started

### Prerequisites

- Xcode 15.0 or later
- iOS 17.0 or later
- macOS for development

### Installation

1. Clone the repository:
```bash
git clone https://github.com/louismoro28-svg/FlixV.git
cd FlixV
```

2. Open the project in Xcode:
```bash
open FlixV.xcodeproj
```

3. Select your target device or simulator from the Xcode toolbar.

4. Build and run the project by pressing `Cmd + R` or clicking the Play button.
